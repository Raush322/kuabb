# Learning Intelligence

Интеллектуальный журнал для корпоративного обучения.

Проект собирает материалы из заданных источников, анализирует их с помощью ИИ и показывает наиболее значимые сигналы для корпоративного обучения, развития сотрудников, технологий и бизнеса.

## Learning Intelligence + Banking

Закрытый intelligence dashboard для корпоративного обучения. Он помогает редакции находить и объяснять сигналы о learning, навыках, людях, технологиях, трансформации бизнеса и финансовом секторе: от исходного материала до возможного влияния на практику обучения.

Проект проектируется как модульный монолит: web-приложение отвечает за журнал и администрирование, а фоновые задачи сбора и AI-анализа со временем будут вынесены в worker. Основное хранилище — PostgreSQL. Redis, Docker Compose и отдельный worker предусмотрены архитектурой, но не входят в первый этап реализации.

Первый рабочий сценарий: **RSS-источник → нормализация и дедупликация статьи → AI-анализ → редакторская проверка → отображение в журнале**. Поддержка API, Sitemap и Web предусмотрена моделью источников, но пока не реализуется.
